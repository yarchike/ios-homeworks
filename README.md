# Social Network App

Приложение социальной сети, разработанное с использованием архитектуры MVVM и паттерна Coordinator. В приложении реализована интеграция с Firebase для аутентификации, хранения данных и загрузки файлов. Поддерживается локализация на русский и английский языки.

## Особенности

- **MVVM архитектура**: Приложение построено с использованием паттерна MVVM для разделения логики и представления.
- **Coordinator Pattern**: Управление навигацией через Coordinator для улучшения тестируемости и организации кода.
- **Firebase Authentication**: Реализация аутентификации с использованием Firebase Auth.
- **Firebase Database**: Хранение данных пользователей и сообщений в Firebase Realtime Database.
- **Firebase Storage**: Загрузка и хранение файлов (например, изображений) в Firebase Storage.
- **UIKit**: Использование UIKit для построения пользовательского интерфейса.
- **Локализация**: Приложение поддерживает два языка — русский и английский.
